# SPIKE-S4.1 — свой рендер: WPF vs WinUI 3 (матрица «карточка+столы»)

- Дата: 13.09.2026 (раунд 0; раунды 1–2 — ждут разблокированной сессии)
- Машина: Windows 11 Pro 26200 (25H2), один монитор 2880x1800 физ., 150%
- Ветка: `s4.1-render-spike`
- Решения план-гейта: без Islands (доки WASDK: «tested for C++ only»);
  ядро матрицы «карточка+столы» (С1–С8); один монитор; тайбрейкер —
  визуальный паритет с нативным тостом.

## Гипотезы (до эксперимента)

- **Г1**: нативный баннер живёт в правом-нижнем углу рабочей области, зона
  ~700x340 физ.пикс @~90 px от низа; раунд 0 уточняет позицию/размер.
- **Г2 (WPF)**: механика матрицы работает (прецедент старого rnotif §9);
  визуал — имитация акрила, не системный материал.
- **Г3 (WinUI 3)**: `AppWindow`+`OverlappedPresenter` даёт показ без
  активации и топмост; `DesktopAcrylicBackdrop` живёт на безрамочном окне;
  пер-мониторный 150% чёткий из коробки.
- **Г4 (WinUI 3)**: столы — пересоздание окна по `EVENT_SYSTEM_DESKTOP_SWITCH`
  (паттерн старого rnotif) срабатывает и для AppWindow.
- **Г5**: клик по карточке → `SetForegroundWindow` отправителю (ALT-трюк) —
  стеконезависимо (уровень HWND).

## Метод

- Эталон: `spikes/tools/native-banner-zone.ps1` — DPI-aware, BMP-дифы зоны
  760x380 физ.пикс @90 px от низа (правый-нижний угол), bbox изменённых
  пикселей (LockBits, допуск 8/канал).
- Карточка: `spikes/tools/render-card-check.ps1` — та же зона;
  `Noise/D300/D1500/AfterExit` (сэмплированный байтовый диф, шаг 211) +
  foreground-чек до/после показа.
- Оба спайк-хоста: `spikes/render/rnotify.SpikeWpf` (bin/Release/
  net10.0-windows10.0.22621.0/rnotify.SpikeWpf.exe) и
 `spikes/render/rnotify.SpikeWinUI` (…/win-x64/rnotify.SpikeWinUI.exe),
  режим `card --ttl N` / `--sticky`; без аргументов — джойстик.
- Центр уведомлений в замерных циклах НЕ чистим (§10a).

## Раунды 1–2 — WPF и WinUI 3 (ОЖИДАЮТ разблокированной сессии)

Сценарии: С1 позиция (BMP-диф зоны), С2 не-активация (foreground-чек),
С3 топмост (над maximize-окном), С4 чёткость 150%, С5 материал рядом с
нативным тостом (глаза), С6 анимация входа/выхода, С7 клик (✕/тело→фокус
жертве), С8 виртуальные столы (Win+Ctrl+→, sticky, пересоздание).
Тайбрейкер — визуальный паритет глазами владельца.
