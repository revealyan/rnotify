# CLAUDE.md — конституция rnotify

Это руководство для Claude Code при работе в этом репозитории.

## Назначение

Диспетчер уведомлений Windows 11 (25H2+): гасить нативный показ полностью
(формула Э1), читать всё из хранилища Центра листенером, показывать своим
рендером по правилам-группам. Продукт для MS Store / winget / GitHub.

## Незыблемые решения (менять только с владельцем)

1. **MSIX с первого дня** — package identity входит в архитектуру (кандидат на
   живые события листенера; подготовлено к стору).
2. **Абсолютный ноль нативного рендера** — никакой логики «показать и быстро
   прихлопнуть»; только превентивное подавление формулой Э1.
3. **Спайк-фёрст**: любое непроверенное утверждение — сначала гипотеза →
   эксперимент → фиксация факта в `C:\devs\docs\win11-notifications-control.md`.
   Опыт старого rnotif (PoC, забытое) можно переиспользовать только как
   гипотезу для перепроверки.
4. **Формула Э1** (валидирована 12.09): глобально `NOC_GLOBAL_SETTING_TOASTS_ENABLED=0`
   + blanket per-app `ShowBanner=0` всем отправителям; при выходе — вернуть
   прежние значения. Доставка в хранилище при этом жива (корм листенера).
5. UI-стек — по итогам спайка (WPF vs WinUI 3).

## Правила работы

- Язык комментариев/доков — русский, UTF-8 без BOM.
- Строгость: `TreatWarningsAsErrors`, nullable, latest LangVersion.
- Релизы: тег → GitHub Actions собирает MSIX → Release. Store — сабмишном из CI
  или Partner Center. Свой код-сигнинг не покупаем, пока не понадобится план Б.
- Регистрация разработчика: MS-аккаунт, страна РФ (может не пустить на
  сабмите → план Б: только GitHub + Certum + winget-community).
- Грабли измерений и работы с уведомлениями — §10a канона (DPI-aware,
  BMP-дифы, отравление рендерера сносом Центра, NOC_* не истина). Перечитать
  перед любым спайком.
