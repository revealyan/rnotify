# rnotify

Свой диспетчер уведомлений Windows 11: система не показывает ничего сама —
приложение гасит нативный рендер на корню, читает поток уведомлений и
показывает всё своими карточками по правилам (по приложению и по контенту).

**Статус**: старт 12.09.2026. Закрыты: формула Э1 (спайк), MSIX-каркас S5.1,
packaged-спайк S5.2 (ключи Э1 из пакета — пара capability +
`RegistryWriteVirtualization`; `NotificationChanged` живой), релизный пайплайн
S5.3a (тег → Release, unsigned), листенер в ядре S2.1 (события, контент
22621 — packaged подтверждён живым прогоном, backlog-фильтр), политика правил
S3.1 (движок матчинга + конфиг v2 с хот-релоадом; delete/killNative сносят из
Центра — `RemoveNotification` из packaged подтверждён живым прогоном),
спайк стека рендера S4.1 (**выбран WPF** — topmost поверх фуллскрина в WinUI 3
недостижим), рендер-карточки S4.2 (стек-3 с вытеснением, ttl/sticky/цвет/click
из правил, killNative, гашение по Removed; видны на всех виртуальных столах),
формула Э1 в продукте S1.2 (нативные баннеры гасятся при работе — весь показ
только наш; возврат при выходе, крах-безопасность маркером), трей и автозапуск
S6.1 (жизнь процесса = трей, закрытие окна сворачивает, выход из меню; старт
с системой по чекбоксу), локализация S6.2 (en-нейтральный + ru-сателлит,
язык ОС + override), имя/иконка отправителя S6.3 (реестр AppUserModelId +
PackageManager), догоняющие после краха S6.4 (floor + липкий поток со
скипом). Далее: остатки Э4 (мультимонитор, док-панель, редактор).

## Сборка и установка (dev)

Однократно (требует консоль с правами администратора — включает dev-mode и
импортирует дев-сертификат в доверенные):

```powershell
powershell -ExecutionPolicy Bypass -File tools/dev-cert.ps1
```

Каждая сборка (сертификат на месте → пакет подписывается автоматически):

```powershell
dotnet build -c Release src/rnotify
```

(каждую команду копируйте отдельной строкой — стрелки в примерах выше только
для связности повествования)

Установка пакета и проверка identity глазами (окно показывает Name/Publisher/
Version из манифеста):

```powershell
Add-AppxPackage src\rnotify\AppPackages\rnotify_0.1.0.0_x64_Test\rnotify_0.1.0.0_x64.msix
Get-AppxPackage revealyan.RNotify        # Name/Version/Publisher
# запуск: окно RNotify; второй запуск молча выходит (single-instance)
Get-AppxPackage revealyan.RNotify | Remove-AppxPackage   # удаление
```

Без дев-сертификата (чистый клон, CI) пакет собирается без подписи — сборка
остаётся зелёной.

## Правила

Конфиг — `%USERPROFILE%\.rnotify\rules.json`, создаётся дефолтным при первом
запуске и правится руками: сохранение подхватывается на лету (дебаунс 300 мс,
без рестарта); битый файл не роняет работу — остаются прежние правила, ошибка
видна строкой в окне.

Формат — группы с правилами; поля правила: `app`/`title`/`body` (матчеры,
объединение AND, пропущенное поле = любое), `match` (`regex` по умолчанию /
`exact` / `contains`, регистр не важен), `action` (`show` / `mute` / `delete`),
`ttl` (`"5s"`/`"3m"`/`"sticky"`, только show), `killNative` (снести нативную
копию из Центра), `click` (`close`/`focus` — с рендером), цвет — на группе.
Первое совпавшее правило побеждает; без матча — показ 5 с. Кривое правило
выбрасывается с отчётом в окне, соседние работают. `app` матчит только AUMID
отправителя (например, `powershell` совпадёт с тостами из powershell.exe).
Пример — в дефолтном конфиге.

## Подавление нативных баннеров (Э1)

Пока приложение работает, нативный показ выключен: глобальный тумблер
`NOC_GLOBAL_SETTING_TOASTS_ENABLED=0` + blanket `ShowBanner=0` каждому
отправителю (новые отправители гасятся при первом уведомлении). Доставка в
хранилище Центра жива — листенер читает весь поток, показываем только своими
карточками. При выходе прежние значения возвращаются (глобальный тумблер,
отсутствовавший до нас, возвращается явной `1` — удаление значения не будит
шелл).

Догоняющие: если процесс убит и нативные оставались погашенными,
непросмотренное при следующем старте показывается карточками (липкие —
закрываешь ты; плашка «Пропустить догоняющие» над стеком; настройки
`catchUpLimit`, `catchUpSticky`).

Крах-безопасность: снапшот прежних значений хранится в
`%USERPROFILE%\.rnotify\suppression.json` и стирается после успешного
возврата; если процесс убили — следующий запуск чинит реестр по маркеру
и применяет формулу заново.

Согласие листенера: если consent не получен (и карточек быть не может),
баннеры по умолчанию НЕ гасятся. Управляется настройкой
`%USERPROFILE%\.rnotify\settings.json`: `suppressWithoutListener: true` —
гасить всё равно (читается на старте, перезапуск для смены).

**Заметка об удалении**: если приложение удалено/переустановлено в момент,
когда формула была применена (маркер остался в `.rnotify\`), баннеры
останутся погашенными — верните тумблер вручную (Settings → System →
Notifications) или удалите значения `NOC_GLOBAL_SETTING_TOASTS_ENABLED` и
`ShowBanner` из `HKCU\...\Notifications\Settings`.

## Трей и автозапуск

Жизнь приложения — в области уведомлений: закрытие окна (X) **сворачивает в
трей**, демон продолжает работать (формула Э1 держит, карточки живут).
Настоящий выход — правый клик по иконке → «Выход» (формула снимается, реестр
возвращается). Левый клик или повторный запуск приложения — развернуть
панель. Меню: «Панель / Автозапуск / Выход».

Автозапуск — чекбокс в меню трея: переключает запись `autostart` в
`settings.json` и системную MSIX StartupTask (видна в Task Manager → Startup
apps). Старт по автозапуску — сразу в трей, без окна; ручной запуск —
с панелью.

## Язык интерфейса

UI — en-нейтральный с русским сателлитом: по умолчанию следует языку ОС
(третий язык получает английский). Override — поле `language` в
`%USERPROFILE%\.rnotify\settings.json`: `"ru"`, `"en"` или отсутствует
(= язык ОС); применяется при запуске, смена — перезапуском. Переводится
хром (меню трея, кнопки, заголовки строк панели); диагностические значения
остаются как есть.

## Карточки

Каждое уведомление с show-вердиктом открывает карточку-оверлей в зоне
нативного баннера (правый-низ): безрамочное неактивируемое topmost-окно,
вход slide+fade, выход fade. Стек: свежая снизу, старые уезжают вверх,
максимум 3 — 4-я вытесняет старейшую (как нативные). Имя отправителя —
человеческое (реестр AppUserModelId / PackageManager; например «Claude Code
(rhub)» с иконкой), иконка — 36×36 при слоте отправителя. Из вердикта правила:
`ttl` (таймер жизни; `sticky` — без таймера), цвет группы — акцент-полоса
слева, `click: focus` — клик по телу поднимает окно отправителя
(AUMID → процесс → ALT-трюк), иначе клик закрывает. `killNative` сносит
нативную копию из Центра, не гася свою карточку; чужой снос (руками из
Центра) гасит карточку. Карточки видны на всех виртуальных столах сразу —
стили неактивируемого окна (канон §9), слежение не нужно. Закрытие
окна-панели гасит и карточки.

## Релизы

Тег `v*` на main → [release-workflow](.github/workflows/release.yml) собирает
MSIX (версия манифеста — из тега: `v0.1.2` → `0.1.2.0`) и вкладывает его в
GitHub Release. Пакет без подписи: для установки на свою машину подписать
дев-сертом (после однократного `tools/dev-cert.ps1`):

```powershell
signtool sign /fd SHA256 /f certs\rnotify-dev.pfx /p <пароль из tools/dev-cert.ps1> rnotify_0.1.0.0_x64.msix
Add-AppxPackage .\rnotify_0.1.0.0_x64.msix
```

Релизная подпись (стор-серт или Certum) — S5.3b после Э2.
