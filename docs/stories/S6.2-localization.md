# S6.2 — локализация UI: ru/en (Э6)

Статус: **done** (14.09 — en-нейтральный + ru-сателлит, язык ОС + override
settings.json; живой прогон: английская ОС → английский UI, `"language": "ru"`
→ русский, сателлит в пакете).

## Что/зачем

Продукт идёт в стор: UI-хром одноязычно-русский. Решения план-гейта (14.09):
**en-нейтральный** (юзер с третьим языком видит английский — стор-стандарт),
**ru-сателлит**; язык — по ОС, override полем `language` в settings.json
(`"ru" | "en" | null` = ОС; смена — перезапуском). Границы: переводим только
**хром** (ключи строк панели, кнопка копирования, заголовок, меню трея);
диагностические ЗНАЧЕНИЯ (вердикты, трейсы Э1/стека) не переводим —
полу-технический канал; термины «Э1»/«Consent (Э2)»/«Baseline» — как есть в
обоих языках. Манифест не трогаем: DisplayName «RNotify» — бренд, описание
локализуется стор-листингом.

## Результат

- `src/rnotify/Strings.resx` (en, 16 ключей) + `Strings.ru.resx` (ru):
  меню трея, заголовок секции, кнопка и фидбек копирования, ключи AddRow.
- `src/rnotify/Strings.cs` — обёртка ResourceManager **руками**: dotnet build
  не запускает VS-генератор resx, CI собирает без Visual Studio. Fallback в
  каждом свойстве (ресурс не найден → en-строка).
- csproj: `<NeutralLanguage>en</NeutralLanguage>`; сателлит `ru/
  rnotify.resources.dll` собирается в пакет автоматически (проверено листингом
  msix).
- `App.ApplyLanguage`: ДО создания окна — `CurrentUICulture` (ru/en/ОС) +
  `FrameworkElement.LanguageProperty.OverrideMetadata` (XAML-форматирование);
  `CurrentCulture` не трогаем (только язык ресурсов). Читает settings.json
  при старте.
- `AppSettings.Language` (string?, null = ОС) — round-trip тестами.
- Применение: `MainWindow.xaml` — `x:Static` (заголовок, кнопка);
  `MainWindow.xaml.cs` — ключи AddRow и фидбек кнопки (формат —
  `CompositeFormat`-кэш, рельсы CA1863/MA0011); `TrayIcon.ShowMenu` — строки
  меню.

## Живой прогон (пакет 0.1.0.0, Win 26200)

- Английская ОС владельца, `language` нет → панель и кнопка английские
  (Mode/Settings/Tray/Rules, Copy all) — нейтральная ветка.
- `"language": "ru"` + перезапуск → панель и меню трея русские («Режим»,
  «Настройки», «Скопировать всё», «Панель/Автозапуск/Выход»).
- Возврат `language: null` → снова английские (язык ОС).

## Разбор

- **dotnet build ≠ VS**: `Generator`-метаданные resx — design-time Visual
  Studio; CLI и CI их не исполняют. Обёртка руками — то, что сгенерировал бы
  генератор, и честнее в репо.
- .NET 10: фабрика `CompositeFormat` — `Parse(string)` (Create нет).
- Культуру ставим ДО создания окна: `x:Static` и ResourceManager читают
  `CurrentUICulture` в момент разрешения строки.
- Сателлит в msix кладётся по `ru/rnotify.resources.dll` — стандартный
  probing .NET, ничего вручную.

**Маршрут чтения**: `Strings.resx` / `Strings.ru.resx` → `Strings.cs` →
`App.ApplyLanguage` → `MainWindow.xaml` (x:Static) → `TrayIcon.ShowMenu`.

**Как проверить руками**: README «Язык интерфейса».

**Отложено сознательно**: перевод диагностических значений панели;
локализация манифеста/Store-листинга; смена языка без перезапуска;
локализация дефолтного rules.json (имена групп — данные пользователя).
