# S8.1 — подкладка-стек + звук + фуллскрин (финал функционала)

Статус: **done** (15.09 — подкладка поiterативным правкам живых прогонов;
звук per-rule + звуковой бланкет (канон-факт); hideOnFullscreen).

## Что/зачем

(1) **Подкладка** — идея владельца (S7.2): при переполнении стека-3 старшая
не пропадает, а складывается. Финальная форма (3 итерации живых прогонов):
ВСЕ скрытые в ОДНОЙ точке (слезинка над тройкой, друг за другом), счётчик
на плашке «Пропустить всё», плашка на фиксированном прижатом месте, наверх
возвращается НОВЕЙШАЯ из скрытых (закрыл 6-ю → заезжает 3-я). (2) **Звук**:
архитектура §9 обещала per-rule sound; живой прогон вскрыл, что родной
дзыньк тоста ЖИВЁТ при погашенных баннерах — формула Э1 глушит показ, не
аудио (канон-факт). (3) **hideOnFullscreen**: поле overFullscreen устарело
(карточки всегда поверх) — владелец гейтом выбрал обратную семантику.

## Результат

- `CardStack`: `_tucked` (потолок 8), Show→переполнение подкладывает
  старейшую видимую; `LayoutTucked` — одна точка (slot3Top − 6 DIP);
  закрытие видимой → повышение новейшей скрытой (`Insert(0)` + обязательная
  пересборка геометрии); `RestackZ` (видимые поверх скрытых — подложенная
  НОВЕЕ в z и накрывала видимую); `CloseAll` (скип). Событие `TuckedChanged`
  на каждом изменении (счётчик плашки живой).
- `CatchUpBanner`: фиксированное место над тройкой; `BringToFront`
  (SetWindowPos topmost-ре-вставка); счётчик = очередь + подкладка.
- `RuleSound` (PlaySound winmm, SND_NODEFAULT): поле `sound` в правиле —
  путь к .wav, играет при показе карточки.
- **Звуковой бланкет**: `SoundFile=""` всем отправителям (пустая строка =
  тишина — канон §3, доказано живьём), priors в маркере (снапшот
  расширен `AppSoundFile`), настройка `suppressNativeSound` (дефолт вкл).
- `FullscreenProbe`: foreground покрывает свой монитор (допуск 2 px) →
  `hideOnFullscreen` в правиле прячет карточку (строка «~ id … скрыта:
  фуллскрин»); уведомление живёт в истории/Центре.
- Тестов 53 (+звуковой бланкет round-trip, выключенность настройкой).

## Живые прогоны (пакет 0.1.0.0, глаза владельца)

- Подкладка: итерации — «уезжает вверх» → одна точка; «3-4 много» →
  z-инверсия найдена; «закрыл 3 — ничего не съехало» → Insert(0)+Relayout;
  «заехала 1, ждал 3» → новейшая из скрытых. Финал: «ну вот другое дело».
- Звук: powershell-тост = 2 звука (родной дзыньк + wav правила) → гипотеза
  «родной живёт при Э1» → rhub = 1 дефолтный (подтверждение) →
  SoundFile="" на одном ключе = тишина (канон-факт) → бланкет на 38:
  «1-й со звуком (wav), 2-й без, rhub без звука».

## Разбор

- **Звук тоста живёт при подавленных баннерах** — тихое открытие месяца:
  формула Э1 не трогала аудио; всё это время юзер слышал дзыньки
  «невидимых» уведомлений. Решение — бланкет SoundFile по образцу ShowBanner
  (priors в маркер, возврат как был: у юзера был свой wav → вернётся wav).
- Z-порядок topmost-окон = порядок создания: докладываемая карточка моложе
  — без RestackZ накрывала живую. SetWindowPos(HWND_TOPMOST) ре-вставкой
  наверх — единый приём для карточек и плашки.
- Повышение обязано пересобирать геометрию сразу: без Relayout карточка
  «числится видимой», стоя на месте подкладки — и порядок путается на
  следующем же закрытии.

**Маршрут чтения**: `Render/CardStack.cs` (tuck/promote/RestackZ) →
`Render/RuleSound.cs` + `Core/Suppression` (звуковой бланкет) →
`Render/FullscreenProbe.cs` → `Render/CatchUpBanner.xaml.cs`.

**Отложено сознательно**: hideOnFullscreen глазами в реальной игре
(эвристика покрывает монитор; проверена логически, живой фуллскрин не
гоняли); звук по умолчанию для всех карточек (выбрана тишина — «звук
привилегия важных»); оборачачивание звука тоста-отправителя (WinRT audio
в XML — копать не стали, бланкет проще).
